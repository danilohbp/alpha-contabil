# 🧾 Sistema de Gestão Contábil - Desktop (Electron + React)

Projeto de extensão universitária com foco em **digitalização de documentos**, **organização de cadastros de clientes** e **gestão interna para escritórios de contabilidade**, com ênfase em sustentabilidade e impacto social.

## 🎯 Objetivo

Desenvolver uma aplicação desktop funcional, segura e prática para auxiliar contadores na gestão de seus clientes e documentos, substituindo processos analógicos por soluções digitais que contribuem com a **redução do uso de papel**, conforme a **Meta 12.5 dos Objetivos de Desenvolvimento Sustentável (ODS 12)** da ONU.

## 🛠️ Tecnologias Utilizadas

- **Electron**: Para criação de aplicativos desktop multiplataforma.
- **React.js**: Interface moderna e reativa.
- **Material UI (MUI)**: Componentes visuais e responsivos.
- **SQLite (better-sqlite3)**: Banco de dados local leve e eficiente.
- **Recharts**: Criação de gráficos interativos para dashboards.
- **Node.js + IPCMain/IPCRenderer**: Comunicação entre camadas main e renderer.
- **JavaScript (ES6+)**: Linguagem principal da aplicação.

## 📋 Funcionalidades

- 🔐 **Login seguro** com autenticação local.
- 👥 **Cadastro de clientes** com dados completos (CPF/CNPJ, endereço, contato).
- 📁 **Upload de documentos digitalizados** vinculados ao cliente.
- 📊 **Dashboard visual** com:
  - Distribuição por tipo de cliente (Pessoa Física ou Jurídica)
  - Gráfico por estados (UF)
  - Cidades com maior número de cadastros
- 🔍 **Busca e listagem com filtros**
- 🗃️ **Armazenamento local seguro** com `userData` do Electron
- ♻️ **Contribuição à sustentabilidade** com eliminação do uso de papel

## 🧠 Motivação e Impacto

Este projeto foi desenvolvido como parte de um **projeto de extensão universitária** visando:

- Melhorar a rotina operacional de pequenos escritórios contábeis
- Aplicar conhecimentos técnicos em contexto real
- Contribuir para os ODS, especialmente:
  
  > **ODS 12 – Meta 12.5**: *"Até 2030, reduzir substancialmente a geração de resíduos por meio da prevenção, redução, reciclagem e reuso."*
